// Repo Structure Overview ``` my-subscription-app/ ├── backend/ │ ├── models.js │ ├── routes/ │ │ ├── auth.js │ │ ├── dashboard.js │ │ ├── podDrafts.js │ │ ├── admin.js │ ├── middleware/ │ │ └── authenticateToken.js │ ├── server.js │ ├── config.js │ └── package.json ├── frontend/ │ ├── src/ │ │ ├── App.js │ │ ├── components/ │ │ │ ├── Dashboard.js │ │ │ ├── PodDraftsManager.js │ │ │ ├── AdminPanel.js │ │ ├── index.js │ ├── package.json ├── README.md └── Dockerfile ``` ## Step 1: Backend Setup - **`models.js`**: Sequelize models for User, Order, PodDraft, Recommendation. - **`middleware/authenticateToken.js`**: JWT auth middleware. - **`routes/auth.js`**: Register/login endpoints. - **`routes/dashboard.js`**: User dashboard API (orders, drafts, recommendations). - **`routes/podDrafts.js`**: POD drafts CRUD API. - **`routes/admin.js`**: Admin routes (basic user/order management). - **`server.js`**: Express app entry point + middleware + route setup. - **`config.js`**: Environment variables config. --- ## Step 2: Frontend Setup (React) - **`App.js`**: Auth flow and routing. - **`components/Dashboard.js`**: User dashboard UI. - **`components/PodDraftsManager.js`**: POD drafts CRUD UI. - **`components/AdminPanel.js`**: Admin dashboard placeholder. - **`index.js`**: ReactDOM render entry. --- ## Step 3: Stripe Integration - Stripe setup in backend (`server.js` or dedicated route). - Webhook handler to sync payment status to orders/subscriptions. - Order creation tied to Stripe payment intent IDs. --- ## Step 4: Run & Test - Use `.env` for config (JWT secret, Stripe keys, etc). - Use `npm run dev` (or with nodemon) for backend. - Use `npm start` for frontend. - Dockerize if desired.
