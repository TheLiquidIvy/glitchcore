Got it! Let’s cover deployment for your full stack app (Node.js backend + React frontend) with best practices, including Docker. --- # Part 3: Deployment Guide --- ## 1. Dockerize Backend and Frontend ### Backend `Dockerfile` ```dockerfile # Use official Node.js 18 image FROM node:18-alpine # Set working directory WORKDIR /app # Copy package files and install deps COPY backend/package*.json ./ RUN npm install --production # Copy backend source COPY backend/ . # Expose port EXPOSE 3001 # Run the server CMD ["node", "server.js"] ``` --- ### Frontend `Dockerfile` ```dockerfile # Build stage FROM node:18-alpine as build WORKDIR /app COPY frontend/package*.json ./ RUN npm install COPY frontend/ . RUN npm run build # Production stage - serve with nginx FROM nginx:stable-alpine COPY --from=build /app/build /usr/share/nginx/html # Copy custom nginx config if needed # COPY nginx.conf /etc/nginx/conf.d/default.conf EXPOSE 80 CMD ["nginx", "-g", "daemon off;"] ``` --- ## 2. Docker Compose (Optional, to run both together) Create `docker-compose.yml` in root: ```yaml version: '3.8' services: backend: build: context: . dockerfile: backend/Dockerfile ports: - "3001:3001" environment: - JWT_SECRET=your_jwt_secret - STRIPE_SECRET_KEY=your_stripe_secret - STRIPE_WEBHOOK_SECRET=your_webhook_secret volumes: - ./backend:/app restart: always frontend: build: context: . dockerfile: frontend/Dockerfile ports: - "80:80" depends_on: - backend restart: always ``` --- ## 3. Environment Variables - Store sensitive keys (JWT secret, Stripe keys) securely. - For local development, use `.env` files. - For deployment (e.g., AWS, DigitalOcean, Heroku), set environment variables in the platform dashboard or with secrets manager. --- ## 4. Database - The backend example uses SQLite for simplicity. - For production, switch to a robust SQL DB like PostgreSQL or MySQL. - Update Sequelize config accordingly. - Use volumes or managed DB service for persistence. --- ## 5. Deployment Platforms - **VPS/Droplets:** Deploy Docker containers to DigitalOcean, Linode, AWS EC2, etc. - **PAAS:** Use Heroku (with Procfile), Render.com, Railway.app for easy deploy. - **Container Services:** AWS ECS, Azure Container Instances, Google Cloud Run. --- ## 6. Sample Commands to Build & Run with Docker Compose ```bash docker-compose build docker-compose up -d ``` - Backend will be at `http://localhost:3001` - Frontend served at `http://localhost` (port 80) --- ## 7. Optional: Nginx Reverse Proxy Setup (if self-hosting) - Use Nginx to serve frontend and proxy `/api` requests to backend. - Example: ```nginx server { listen 80; location / { root /usr/share/nginx/html; try_files $uri /index.html; } location /api/ { proxy_pass http://localhost:3001/api/; proxy_http_version 1.1; proxy_set_header Upgrade $http_upgrade; proxy_set_header Connection 'upgrade'; proxy_set_header Host $host; proxy_cache_bypass $http_upgrade; } } ``` --- ## 8.
